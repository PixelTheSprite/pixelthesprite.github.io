# pixelthesprite.github.io

Mike's personal portfolio: a small, 90s-style home for side projects, some hand-built and some AI-assisted.

Live site: https://pixelthesprite.github.io

Built with GitHub Pages and the [Modernist](https://github.com/pages-themes/modernist) Jekyll theme. Edit `index.md` for content and `_config.yml` for the site title and description. To preview locally, run `bundle exec jekyll serve` with the `github-pages` gem installed.
